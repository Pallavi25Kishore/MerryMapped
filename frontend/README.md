# Frontend

Next.js (TypeScript, Tailwind, shadcn/ui, MapLibre): the MerryMapped web app.

Run it: `npm install` once, then `npm run dev` and open http://localhost:3000.

## Background picture (not in git)

The winter night background is a free Magnific picture ("winter night background festive holiday
design"). Its licence allows use on the website with the credit "Designed by Magnific" and a link
(shown in the footer), but forbids making the file available for download, so it is git-ignored.
To set it up, download it from magnific.com and make the web copy (1920 px wide, about 680 KB):

    sips -Z 1920 -s format jpeg -s formatOptions 62 <downloaded file> --out public/backgrounds/winter-night.jpg

Without it, the site shows a plain teal sky.
